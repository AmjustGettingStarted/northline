# News Mini App 📰

A lightweight, responsive single-page web application that aggregates real-time news across multiple categories. Users can seamlessly browse top headlines, read concise article summaries, and access full stories via direct links.

##  Features

- **Category Filtering:** Quickly switch between news topics including **Technology**, **Science**, **Sports**, **Politics**, and general headlines.
- **Real-Time News Fetching:** Dynamically retrieves news articles using asynchronous API requests.
- **Clean Article Cards:** Displays concise summaries, publication dates, source information, and visual thumbnails.
- **Direct Article Access:** Integrated buttons to open full original articles in a new browser tab.
- **Responsive Design:** Optimized layout for seamless viewing on desktops, tablets, and mobile devices.
- **User Feedback:** Built-in loading states and error handling for smooth navigation.

---

##  Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Data Source:** RSS / Public News API endpoints

##  Getting Started

### Prerequisites

All you need to run this project is a modern web browser (e.g., Google Chrome, Mozilla Firefox, Safari, Edge).

### Installation & Usage

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/news-mini-app.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd news-mini-app
   ```

3. **Open the application:**
   Double-click `index.html` or open it directly in any modern browser.
